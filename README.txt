HOW TO RUN:
1. Double-click "start-all.bat"
   - Automatically detects Java 21 (or installs Eclipse Temurin JDK 21 via winget if missing).
   - Starts the Spring Boot backend engine on port 8080.
   - Synchronizes directly with Google Cloud Firestore in real time.
   - Opens the live Web Portal (https://nexusarena-esports.web.app).
   - Launches the Organizer Desktop Application (JavaFX Cyberpunk UI).

2. OR double-click "start-desktop.bat"
   - Launches the Desktop Organizer Client directly.
   - The desktop app automatically checks for and auto-starts the backend engine!
